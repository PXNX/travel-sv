# Kartenebenen

Die Reiseansicht enthält vier austauschbare Grundkarten: OpenStreetMap für die allgemeine Orientierung, Satellit für Luftbilder, OpenRailwayMap für Bahn- und U-Bahninfrastruktur sowie ÖPNVKarte/OpenPtMap für allgemeine öffentliche Verkehrsnetze.

Die ÖPNVKarte-Ebene verwendet `https://tile.memomaps.de/tilegen/{z}/{x}/{y}.png`. Laut OpenStreetMap-Wiki zeigt OpenPtMap neben Eisenbahnstrecken abhängig von der Zoomstufe auch Bus- und Tramlinien. Die Anwendung speichert eine begrenzte Zahl dieser Kacheln lokal, damit bereits angesehene Kartenausschnitte offline verfügbar bleiben.

Quelle: https://wiki.openstreetmap.org/wiki/Openptmap
